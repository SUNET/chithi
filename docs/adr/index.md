# Architecture decisions

These records capture the design choices behind Chithi — privacy
defaults, protocol picks, sync architecture, OAuth flows. Each ADR
is short and stands on its own; they're numbered in roughly the
order they were made, but later ADRs sometimes supersede earlier
ones rather than building on them strictly.

When a future change rethinks one of these, the new ADR notes which
older one it replaces, and the old ADR keeps a header pointing at
its successor — that way the trail of why-we-did-this stays
followable for anyone reading the codebase later.
